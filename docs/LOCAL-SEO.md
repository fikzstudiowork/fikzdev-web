# LOCAL SEO — FikzDev

Publish a `/lokasi/[slug]` page only when **all** are true:

1. Unique local context (factual, not city name swap)
2. Unique FAQ for that location
3. Proof: case study, testimonial, or verifiable detail for that area
4. Page passes copy review in `docs/COPYWRITING.md`

Do not generate mass location pages or near-duplicates. Unready locations stay off the sitemap.
